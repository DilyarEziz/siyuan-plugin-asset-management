## 更新日志

### v2.7.0

**备注支持笔记链接、买断/预付快速退役**

- 新增：备注支持插入笔记链接——在备注输入框输入 `[[` 或 `【【`（中英文输入法都支持）即弹出笔记搜索列表，点选后以 `[标题](siyuan://blocks/块ID)` 形式插入；详情卡与编辑表单预览里可点击直达对应笔记。只接受思源块 ID 协议，其他 URL 按普通文字展示；表单预览里跳转不丢未保存内容。资产备注、种草理由、拔草原因、退役 / 转让 / 维保备注全部支持；手机端浮层自动滚入可视区、点击备注光标落末尾不拆双链、键盘弹起后光标行保持在可视区内，光标与浮层描边跟随主题色。
- 新增：买断、预付权益快速退役——卡片「•••」菜单新增「标记退役」（轻量确认弹窗居中、主题色确认键，退役日期=今天；预付余额 >0 时提示余额连同流水保留）；已退役显示「重新启用」随时恢复；退役 / 恢复后首页列表即刻刷新。买断 / 预付编辑表单同步补「物品状态」pill（通用样式对齐实物），已退役打开表单可查看 / 修改退役日期。实物维持编辑表单退役入口、订阅由到期投影与续订管理，均不加退役按钮。预付快捷记账（充值 / 消费 / 退款 / 记次数 / 校正）改为插件内液态玻璃 sheet，与维保同款展示，不再弹在插件 UI 之外。
- 改进：`retired` 状态不再限于实物，全部 owned 类型均可退役；旧数据从未存在非实物退役记录，放宽为纯增量约束，存量文件校验不变，无迁移无重置。

### v2.6.8

**续订周期可编辑可删除、续订后到期日展示修正、手机端下拉修复**

- 新增：订阅历程支持逐期编辑——产品详情卡的「订阅历程」里每一期都有「编辑」按钮，开始日期、到期日写错了直接改；保存时自动校验与相邻周期不重叠，原始记录作废留档、全程可追溯。
- 新增：误续订可以删除——最新一期会显示「删除」按钮（至少有两期时才提供），撤销不小心记下的续订：这一期的付款金额一并作废，净成本、日均成本与订阅报表随之回退；操作记入操作日志。
- 修复：明明续订了，产品卡上的到期日仍按原来的结束日展示——现在卡片到期日、首页提醒和排序都按最新一期的结束日计算，与「已续订」徽章一起正确反映续订后的状态。
- 修复：手机端下拉选项无效——计费周期 / 币种下拉和日期选择器可能整个弹到屏幕外；现在弹层自动钳制在屏幕内、放不下时向上弹出，点外部收起改用触摸更可靠的指针事件。
- 改进：首页四个筛选下拉（状态 / 类型 / 排序 / 筛选）样式统一——「全部状态」的选中高亮 + 8px 圆角，明暗主题一致。
- 修复：删除预付流水一直失败（操作日志类型未登记），已补录白名单。

### v2.6.7

**过保措辞收口、备注支持加粗、详情卡文字可选中**

- 新增：备注支持行内 Markdown——加粗 `**文字**`、斜体 `*文字*`、下划线 `++文字++`、删除线 `~~文字~~`、行内代码，产品详情卡与编辑表单预览同步渲染；保存的原文不变，HTML 会被安全转义。
- 新增：备注编辑支持思源同款快捷键——⌘/Ctrl+B 加粗、⌘/Ctrl+I 斜体、⌘/Ctrl+U 下划线、⌘/Ctrl+Shift+S 删除线、⌘/Ctrl+Shift+K 行内代码，选中一键包裹、再按取消。
- 新增：备注预览点击定位——点渲染备注的任意位置即可从该处开始编辑；编辑时光标行自动保持在保存按钮上方。
- 改进：产品详情卡里的备注等文字现在可以拖动选中复制了——思源面板默认禁止选中文字，详情卡已显式放开；拖选时松开到卡片外也不会再误关详情卡。
- 改进：保修与订阅的到期提醒彻底分开——实物保修临期显示「即将过保」（订阅仍显示日期 / 「N 天内到期」），保修当天显示「今日过保」，首页到期提醒和报表「即将到期」同步生效。
- 改进：实物产品保修到期后显示「已过保」，不再误显订阅口径的「已过期」；列表与矩阵卡片同步。
- 改进：过保的产品在产品列表里不再变成灰色圆点——灰色只表示退役（含到期未续的订阅），是否过保看卡片上的「已过保」徽章即可。
- 改进：次数权益卡片底部「剩余 N 次 · ¥X/次」数字改用浅色次要色调；首页「已退役」分割线延伸到两端，与卡片边缘对齐。
- 改进：产品卡片底部「日均成本」标签简化为「日均」，信息更紧凑。
