# 资产管理

**把「拥有」和「付费」都放到一处，随时看清每一笔值不值。**

资产管理是住在思源笔记侧边栏里的个人资产管家。实物、订阅会员、储值卡……把它们记在同一处：哪些在役、哪些已退役、每件东西每天花你多少钱、哪个会员快要到期——打开侧栏，一目了然。

## 功能特性

### 三类资产，一处管理

- **实物**——数码、家电、家具，任何你买下的东西
- **虚拟会员**——订阅制与买断制都支持
- **预付权益**——储值卡余额、次数卡余量，实时可查

### 从「想买」到「退役」的完整生命周期

- 三种状态：种草（想买）→ 在役（使用中）→ 退役
- 种草的东西买回家，一步转为在役资产；不想买了，拔草放下
- 种草期间还能跟踪期望价格变化，降价涨价心里有数

### 算清「值不值」

- **日均成本**——自动算出每件东西每天花你多少钱
- **折旧跟踪**——多种折旧方式，看价值随时间如何变化
- **目标日均价**——设个目标，看还差多久达标、是否已经回本

### 到期不忘

- 五级到期徽章，越临近越醒目
- 自动检测过期；首页「即将到期」提醒，不让任何会员悄悄浪费

### 多币种

- 支持人民币 / 美元；首页按人民币汇总总额，卡片同时显示换算价

### 记录与整理

- 彩色标签，按自己的方式归类
- 维保记录、使用记录，每件东西的历史都有据可查
- 报表一览：分类排行、标签排行、金额趋势、价格排行

### 与思源笔记联动

- 可选启用自动维护的资产索引文档，文档移动或重命名后仍保持关联
- 复制或插入原生资产块引用，并在产品卡查看反链、已打标块与手动关联笔记
- 从块引用直接打开产品卡，同时保留修饰键原生跳转和桌面右键 / 移动端长按入口

### 视图与搜索

- 列表 / 矩阵两种视图，宽窄屏都舒服
- 状态、分类、标签筛选与排序，加上关键词搜索，再多资产也找得到

### 数据始终是你的

- JSON 备份与恢复、Markdown 导出
- 数据保存在思源工作空间内，随思源同步，卸载不丢数据
