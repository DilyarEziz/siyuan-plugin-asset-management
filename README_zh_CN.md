## 更新日志

### v2.6.7

**过保措辞收口、备注支持加粗、详情卡文字可选中**

- 新增：备注支持行内 Markdown——加粗 `**文字**`、斜体 `*文字*`、下划线 `++文字++`、删除线 `~~文字~~`、行内代码，产品详情卡与编辑表单预览同步渲染；保存的原文不变，HTML 会被安全转义。
- 新增：备注编辑支持思源同款快捷键——⌘/Ctrl+B 加粗、⌘/Ctrl+I 斜体、⌘/Ctrl+U 下划线、⌘/Ctrl+Shift+S 删除线、⌘/Ctrl+Shift+K 行内代码，选中一键包裹、再按取消，输入框下方有快捷键提示。
- 改进：产品详情卡里的备注等文字现在可以拖动选中复制了——思源面板默认禁止选中文字，详情卡已显式放开；拖选时松开到卡片外也不会再误关详情卡。
- 改进：保修与订阅的到期提醒彻底分开——实物保修临期显示「即将过保」（订阅仍显示日期 / 「N 天内到期」），保修当天显示「今日过保」，首页到期提醒和报表「即将到期」同步生效。
- 改进：实物产品保修到期后显示「已过保」，不再误显订阅口径的「已过期」；列表与矩阵卡片同步。
- 改进：过保的产品在产品列表里不再变成灰色圆点——灰色只表示退役（含到期未续的订阅），是否过保看卡片上的「已过保」徽章即可。
- 改进：次数权益卡片底部「剩余 N 次 · ¥X/次」数字改用浅色次要色调；首页「已退役」分割线延伸到两端，与卡片边缘对齐。
- 改进：产品卡片底部「日均成本」标签简化为「日均」，信息更紧凑。

### v2.6.6

**删除更顺手、界面更稳定、过期订阅自动归入退役**

- 新增：AI 助手支持品牌与购买渠道——可以按名称新建品牌、渠道条目，并在创建或修改资产时直接设置品牌与渠道。
- 新增：首页产品列表中，所有退役产品统一排到最后，与前面的产品之间以一条「已退役」分隔线区分，列表一目了然。
- 改进：品牌、渠道、标签随时可以删除——即使还有资产在用，删除时插件会把这些资产的品牌 / 渠道自动设为「未设置」、从标签列表自动移除该标签，并提前告知会影响几项资产，不再需要先逐个改资产才能删。
- 改进：删除品牌、渠道、标签前都会先二次确认——点「删除」后确认才会真正删除，防止误删。
- 改进：设置窗口高度固定不变——以插件主界面高度为基准，切换各个设置页时窗口不再忽高忽低；内容较多时在窗口内上下滚动查看。
- 改进：订阅到期后自动归入退役——不再停留在「在役」；首页筛选「在役」不再包含过期订阅，「已退役」则包含它们，首页与报表的在役 / 退役数字同步更新；过期订阅卡片会显示灰色「已过期」标记，开通了自动续费的订阅仍按原样显示「待续订」。
- 改进：报表里的标签、品牌、渠道排行默认全部显示——去掉设置页的「报表显示」开关区，不再需要手动开启，设置更简洁。
- 修复：直接新建的产品不再显示「种草历程」——只有真正经历过种草的产品（正在种草中，或从种草池购买而来）才展示种草时间和心动记录。

### v2.6.5

**品牌与入手途径、筛选升级与报表维度分析**

- 新增：资产可标注品牌和入手途径——品牌如小米、华为，途径如京东、淘宝、线下；编辑资产时在「品牌」「入手途径」栏选择或新建，条目名称和颜色都支持自定义。
- 新增：首页「筛选」升级为标签、品牌、途径三组可切换的多选筛选，三组之间可自由交叉组合——例如同时勾选「小米」和「京东」，只看从京东买的小米产品。
- 新增：报表新增「维度分析」——按品牌、按入手途径的花费排行，点击条目即可查看对应资产的明细；可在设置里选择显示哪些排行板块。
- 改进：标签数量限制取消，想加几个加几个。
- 改进：表单必填项带红点标识，选填项无需填写，哪些必须填一眼便知。
